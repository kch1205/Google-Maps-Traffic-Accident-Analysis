# Google Maps Traffic & Accident Analysis

##  Project Overview

This project analyzes road accident data to identify traffic hotspots, accident severity patterns, environmental influences, and time-based accident trends using Python and Power BI.

## Objectives

- Analyze accident trends over time
- Identify accident-prone locations
- Study weather and road condition impacts
- Understand accident severity patterns
- Build an interactive Power BI dashboard

## Key Insights

- Identified accident hotspots using geospatial analysis of latitude and longitude coordinates.
- Analyzed accident trends across different time periods to identify peak accident hours and high-risk periods.
- Evaluated accident severity distribution and casualty impact across different severity categories.
- Assessed the influence of weather conditions, road surface conditions, and lighting conditions on accident occurrence.
- Compared accident patterns between urban and rural areas to understand regional risk differences.
- Developed an interactive Power BI dashboard to support data-driven road safety analysis and decision-making.
- Detected recurring accident clusters that may require targeted traffic management and safety interventions.
- Generated actionable insights that can help improve road safety planning and accident prevention strategies.
